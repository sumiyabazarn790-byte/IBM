Миний тухай

Намайг Сумъяабазар гэдэг. Би full-stack вэб хөгжүүлэгч чиглэлээр суралцаж байна. React, Node.js, MySQL болон Tailwind CSS технологиудыг ашиглан өгөгдлийн сангийн өндөр гүйцэтгэлтэй, хэрэглэгчид ээлтэй вэб интерфейс, системүүд бүтээх сонирхолтой.

Миний ур чадварууд

HTML5 - 95%
CSS3 - 90%
React JS - 85%
MySQL - 80%

Хэрэгжүүлсэн төслүүд

1. Сургуулийн удирдлагын систем

Prisma ORM болон JWT ашиглан багш, сурагчдын бүртгэл, аудит логийг хянадаг API бэкэнд систем.

2. Номын сангийн LMS вэбсайт

Next.js App Router болон Framer Motion хөдөлгөөнт анимейшн ашигласан ном хайлтын систем.

3. Yucca Packaging landing page

Glassmorphism дизайн стиль болон Tailwind CSS ашиглаж хийсэн хариу үйлдэлтэй нүүр хуудас.
